# Boralog

Boralog est un projet de logiciel métier collaboratif pour les petites structures du spectacle vivant : compagnies, bureaux de production, artistes, techniciens, administration, diffusion et logistique.

## Idée centrale

Boralog doit éviter qu'une personne centrale devienne à elle seule la mémoire de l'organisation.

Le produit relie trois choses :

**MESSAGES → INFORMATION → ORGANISATION**

Les échanges professionnels restent simples, mais les informations utiles deviennent retrouvables, partageables et exploitables dans les dossiers de production.

## Principes

- une seule source de vérité pour chaque projet, date et information structurée ;
- chacun voit ce qui est utile à son rôle et à ses autorisations ;
- les échanges privés peuvent rester hors de Boralog ;
- Boralog est l'espace professionnel commun ;
- une information saisie une fois doit pouvoir alimenter les usages concernés ;
- le cœur du produit doit fonctionner sans IA ;
- l'IA pourra rester une couche facultative de confort, jamais une dépendance critique.
